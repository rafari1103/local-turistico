**Lapa a Pé — Guia Turístico**

Projeto independente desenvolvido para praticar os fundamentos de HTML e CSS, apresentando pontos turísticos, cultura e curiosidades da região da Lapa, no Rio de Janeiro.

**Sobre o projeto**

A página foi idealizada e desenvolvida por mim, aplicando os conhecimentos adquiridos nos estudos de front-end. O projeto passou por reformulações visuais e estruturais durante seu desenvolvimento.

**Fotografias e direitos autorais**

O projeto utiliza fotografias autorais, registradas especialmente para a página, e imagens de bancos com licença de uso, como o Pexels.

**Ferramentas utilizadas**

HTML5 e CSS3: estruturação e estilização da página.

Git e Git Bash: versionamento e atualização do repositório no GitHub.

DevDocs.io: consulta à documentação e experimentação de recursos.

Adobe Color: definição da paleta de cores.

Google Fonts: pesquisa e escolha da tipografia.

Visual Studio Code: ambiente de desenvolvimento.
